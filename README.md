# Последний лифт — v0.2

Браузерная игра: погоня от зомби, странный лифтёр, шашки 6×6 и анимированная концовка поражения.

## Запуск
Откройте `index.html` в браузере или опубликуйте файлы в GitHub Pages.

## Новое в v0.2
- При поражении двери лифта открываются, приближаются зомби, появляется пиксельная зелёно-красная масса с косточками.
- После анимации доступны реванш и возврат в начало.
- Сцену можно проверить, проиграв шашечную партию.

Проект не требует сервера, зависимостей и сборки.
