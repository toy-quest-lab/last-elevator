# Последний лифт — прототип 0.1

Самостоятельная браузерная мини-игра (HTML/CSS/JS), без сервера и внешних библиотек.

## Запуск
Откройте `index.html` в браузере. Для GitHub Pages: создайте **отдельный** публичный репозиторий `last-elevator` в аккаунте `toy-quest-lab`, загрузите содержимое папки в корень ветки `main`, затем Settings → Pages → Deploy from a branch → main → / (root). Адрес после публикации: `https://toy-quest-lab.github.io/last-elevator/`.

## Реализовано
- Стартовый экран, погоня, лифт, появление лифтёра.
- Играбельная доска 6×6, игра против простого бота.
- Обязательное взятие, цепочки взятий, дамки, финал победы/поражения.
- Поддержка телефона и компьютера.

## Ограничения
Это **черновой прототип**, не релиз для Яндекс Игр. Визуальные персонажи пока emoji-заглушки, а не согласованные пиксельные спрайты; нет звука, анимационной погони, сохранений, SDK площадки и сложного ИИ. Правила 6×6 требуют дальнейшего тестирования, в частности логики дамок и взятий.
