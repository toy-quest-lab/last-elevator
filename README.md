# ПОСЛЕДНИЙ ЛИФТ

Короткий мобильный хоррор от первого лица: погоня по школьному коридору до лифта, сломанная панель, лифтёр из потолочного люка и партия в русские шашки 6×6. Три исхода: победа (одно из шести мест), поражение, ничья.

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Откройте в браузере адрес, который напечатает Vite. По умолчанию сервер слушает порт 8080. Сборка и проверка типов:

```bash
npm run build
npm run typecheck
```

Проверка правил шашек:

```bash
node --experimental-strip-types --test src/game/checkers.test.ts
```

Игра целиком клиентская. База данных и вход для самой игры не используются: экран — один маршрут `/`.

Звук появляется только после жеста игрока (кнопка «Начать игру» или «Звук»). Отдельных аудиофайлов нет.

## Где лежит игра

- Логика, сцены и шашки: `src/game/` (`game.ts`, `checkers.ts`, `audio.ts`, `art.ts`)
- Экран и кнопка «Ещё раз»: `src/components/ElevatorGame.tsx`
- Стили кнопок: `src/styles.css`
- Картинки и ролик поражения: `public/game/`
- Звук: Web Audio API, `src/game/audio.ts`

Подробный отчёт для передачи проекта — в `HANDOFF.md`.

## Правила шашек

Поле 6×6, обязательное взятие, серии взятий, дамки, ничья по троекратному повторению или 40 ходам без взятия. ИИ — альфа-бета. Эту механику не стоит менять вместе с картинкой.

## Библиотеки

Зависимости перечислены в `package.json` и зафиксированы в `package-lock.json`. Это обычные пакеты с открытыми лицензиями (в основном MIT): React 19, TanStack Start, Vite, Tailwind. Отдельных платных ассетов и звуковых библиотек нет. Графика в `public/game` сделана для этой игры.

Каталог `node_modules` в архив не входит. Его восстанавливает `npm install`.

## Тестовая публикация GitHub Pages

Для статического размещения в отдельной папке: `npm run build:static`.
Содержимое `dist/` размещается в `/last-elevator/grok/`; базовый путь ресурсов относительный.
Исходная серверная сборка `npm run build` сохранена. Механика и графика не изменены.

## Основная версия

Игра опубликована по https://toy-quest-lab.github.io/last-elevator/.
В main находятся полный исходный проект и готовая статическая сборка в корне.
Обновление: npm install, npm run typecheck, npm run build:static; затем скопировать dist/index.html и содержимое dist/assets и dist/game в корень публикации.
GitHub Pages публикует main; .nojekyll сохраняет каталоги с подчёркиванием.
