# Последний лифт — gameplay rebuild

Ветка `gameplay-rebuild` — экспериментальная сборка, **не опубликованная основная версия**.

## Реализовано в первом проходе
- Полноэкранная мобильная сцена погони от первого лица с репликой «Лифт! Я должен успеть!».
- Переход с закрыванием створок в лифт.
- Адаптивные размеры панели управления и шашечного поля.
- Сохранена логика шашек 6×6 и прежние концовки.

## Не завершено
- Полный браузерный и мобильный тест всех сцен.
- Единый игровой HUD для меню, лифтёра и финалов.
- Новые спрайты, звуки и анимации.
- Отдельная концовка при ничьей и полноценная проверка условий ничьей.

## Как посмотреть ветку
В GitHub откройте `gameplay-rebuild`. Для публикации отдельно требуется настроить GitHub Pages на эту ветку или развернуть preview. **Ветка сама по себе не меняет опубликованную игру.**

Не сливать в `main` до тестирования полного маршрута.
