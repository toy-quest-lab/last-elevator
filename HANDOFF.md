# Передача проекта «Последний лифт»

Дата снимка: 13 октября 2026. Это последняя рабочая версия, которую правили в диалоге. Новые механики в этот архив не добавлялись.

## 1. Структура

```
src/game/game.ts        сцены, ввод, отрисовка
src/game/checkers.ts    русские шашки 6×6 и ИИ
src/game/checkers.test.ts
src/game/audio.ts       процедурный звук (Web Audio)
src/game/art.ts         загрузка картинок из /game/
src/components/ElevatorGame.tsx
src/styles.css
src/routes/index.tsx    единственный экран игры
public/game/            все картинки и gore.mp4
package.json            зависимости
package-lock.json
```

Остальные каталоги (`src/lib`, `scripts`, `server`, `migrations`) — каркас TanStack Start. Игра их почти не вызывает. Вход и база для прохождения не нужны.

`node_modules` в архив не входит.

## 2. Что менялось по ходу работы

- Погоня от первого лица по коридору российской школы (`public/game/school.jpg`). Камера зумится к дальней двери. Отдельная серая «дверь-наклейка» убрана: она была в другом стиле и висела не в перспективе.
- Оборачивание назад, зомби и тянущаяся рука остаются. Рука — спрайты `hand-1.png` … `hand-4.png`.
- Вход в кабину, захлопывание дверей, панель кнопок.
- Панель — `public/game/panel-keys.png`. Нажимаются сами круглые кнопки этажей, не пустая стена. Второй нажим ломает панель, из люка вылезает лифтёр.
- Лифтёр появляется из люка. Реплика одна, в облачке: «Шашечки или ехать?». Кнопка «Ехать» неактивна. «Шашечки» начинает партию.
- Шашки 6×6: обязательное взятие, серии, дамки, ничья повтором или по лимиту ходов без взятия.
- Победа: случайное место из шести (`ending.jpg`, `end-home.jpg`, `end-child.jpg`, `end-meadow.jpg`, `end-island.jpg`, `end-dacha.jpg`). У каждого своя фраза лифтёра и табличка «Конечная».
- Дом: на столе чай в подстаканнике и бутерброды с маслом, плюс нарисованный пар.
- Луг: трава и облака сдвигаются по горизонтальным полоскам кадра.
- Остров: то же для облаков, пальм и воды, плюс летящие птицы поверх кадра.
- Поражение: двери, зомби, рука, затем ролик `gore.mp4` в режиме screen (чёрный пропадает, остаётся красное). Звук ролика выключен. Вместо него хлюпанье из `audio.ts`. Надпись «Поездка окончена» подгоняется по ширине плашки.
- Кнопка «Ещё раз» — HTML поверх канваса. Реплики в победе, поражении и ничьей подняты, чтобы её не перекрывать.
- Звук весь процедурный. Файлов wav/mp3 нет.

## 3. Что работает

Проверено на этой сборке перед упаковкой:

- `http://127.0.0.1:8080/` отвечает 200.
- Картинки концовок, школа, панель, спрайты руки, зомби, лифтёра и `gore.mp4` отдаются с кодом 200.
- `src/game/checkers.test.ts`: 7 тестов, все прошли.
- `@tanstack/react-start` установлен как `1.168.60`.

Сцены по порядку: меню → погоня → двери кабины → панель → лифтёр → шашки → поездка → победа. Проигрыш в шашках ведёт в поражение. Ничья — отдельная сцена. Кнопка «Ещё раз» возвращает в погоню.

Звук включается после нажатия «Начать игру» или «Звук». До жеста браузер его блокирует. Это проверено по коду (`audio.unlock()` в `start()`), отдельным прогоном наушников не подтверждалось.

Полный клик-проход «меню → победа» и «меню → поражение» в этом шаге заново не прогонялся. Эти ветки собирались и смотрелись раньше по ходу правок.

## 4. Что ещё сырое

- Коридор. Дальняя дверь — та, что уже нарисована на `school.jpg`, а не отдельная модель лифта. Приближение — зум всей фотографии к точке схода. Игрок всё ещё считает, что бег и дверь выглядят недостаточно естественно. Зомби при взгляде назад и рука оставлены как есть: их просили пока не переделывать.
- Стиль спрайтов зомби и руки (пиксель) не совпадает с живописным коридором и живописными концовками.
- Детство, дача и остановка в пустоте — неподвижные картинки. Ветер и птицы есть только у луга и острова. Пар только у дома.
- `public/game/panel.jpg` и `palms.png` лежат в папке, но текущий код их не грузит. Панель берётся из `panel-keys.png`.
- `corridor.jpg` и `doors.jpg` тоже загружаются (`art.ts`), но погоня рисует `school.jpg`.
- Анимация луга и острова — сдвиг горизонтальных полос картинки. На краях кадра может быть заметный шов.
- Второй нажим любой кнопки этажа сразу ломает панель. Отдельного «правильного кода» нет.
- Каркас вокруг игры (auth, PWA `/__grok/`, база) для прохождения не нужен. Выкидывать его не стали, чтобы `npm install` и `npm run dev` совпадали с этой средой.

## 5. Как запустить локально

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Открыть адрес из вывода Vite. Порт по умолчанию — 8080.

```bash
npm run typecheck
npm run build
node --experimental-strip-types --test src/game/checkers.test.ts
```

`npm test` гоняет тесты каркаса, не шашки.

## 6. Библиотеки и сервисы

Игровой код не ходит во внешние API. Всё нужное лежит в репозитории.

- React 19, Vite 8, Tailwind 4
- TanStack Router и TanStack Start `1.168.60` (не ниже: более ранние версии Start уязвимы)
- TypeScript 5.7
- В `package.json` также есть better-auth, pg, pglite, Kysely и набор Radix. Игровой экран их не использует. Они остаются, потому что на них собран каркас приложения.

Звуковых SDK нет. Графика — файлы в `public/game`, лицензия отдельных стоков не прилагается: кадры сделаны для этой игры.

Секретов и ключей в игровых файлах нет. Пути вида `/workspace` в `src/game` не используются.
