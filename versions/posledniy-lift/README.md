# ПОСЛЕДНИЙ ЛИФТ

Короткий мобильный хоррор от первого лица. Портретный экран, русский язык. Игрок бежит по школьному коридору от зомби, заскакивает в лифт, ломает кнопки, и из люка в потолке спускается лифтёр. Он спрашивает: «Шашечки или ехать?» Ехать нельзя. Надо сыграть с ним в русские шашки 6×6. От партии три исхода: победа, поражение, ничья.

Звук включается только после жеста: «Начать игру» или «Звук». Кнопки «Звук» и «Ещё раз» — поверх холста. Всё остальное рисуется на canvas или идёт роликом.

## Как проходит партия

1. **Обложка.** Постер и кнопка «Начать игру».
2. **Погоня.** Ролик: зомби в школьном коридоре, человек добегает до лифта, двери захлопываются. Когда ролик кончается, открывается панель.
3. **Панель.** Кнопки лифта. Они не работают. После нескольких нажатий сразу появляется лифтёр, без отдельного кадра с люком.
4. **Лифтёр.** Ролик: он слезает с потолка, усмехается и зависает. Пока игрок читает текст, он чуть дышит, красный глаз иногда вспыхивает, под это играет тревожный звук. Фраза: «Шашечки или ехать?» Кнопка «Ехать» ничего не даёт. «Шашечки» — партия.
5. **Шашки.** Доска 6×6, игрок ходит белыми. Лифтёр — голографический бюст с двумя руками, слегка плавает в рамке. Это тот же человек, что в ролике, не старый пиксельный водитель.
6. **Исход.**
   - Победа: лифтёр (новый, не старый) уезжает в люк, лифт едет, затем одна из концовок.
   - Поражение: ролик с зелёной жижей. Удар звучит один раз, дальше жижа стекает без резкого повтора. Надпись «Поездка окончена».
   - Ничья: ролик со спиралью. Крутится без чёрной дырки на стыке. Реплики лифтёра и игрока.

На победе, поражении и ничьей внизу кнопка «Ещё раз». Она начинает партию с погони, а не с панели.

## Победа: шесть мест

Место выбирается случайно. У каждого своя фраза лифтёра.

| Место | Что на экране | Фраза |
|---|---|---|
| Пересадка | Кадр остановки | «Пересадка на автобус. Билеты у водителя.» |
| Дом | Кадр, пар из самовара | «Приехали. Дома.» |
| Двор | Ролик с качелями | «Выходи. Лето ещё не кончилось.» |
| Луг | Картинка: облака едут, ветер только по траве | «Конечная. Можно просто постоять.» |
| Остров | Берег, прибой и птицы | «Дальше только море.» |
| Дача | Ролик веранды: пар, листья уже лежат | «Садись. Чай уже стынет.» |

На даче и во дворе картинка — ролик. «Конечная», реплика, «Звук» и «Ещё раз» рисует игра поверх. На остальных концовках табличка и реплика тоже на холсте.

## Шашки

Русские шашки, поле 6×6, только тёмные клетки.

- Брать обязательно, если есть взятие. Длину серии игрок выбирает сам, максимум не обязателен.
- Простая бьёт и вперёд, и назад.
- Дошла до последней линии — становится дамкой. Если это случилось посреди взятия, серия обрывается.
- Дамка летает.
- Снятые шашки исчезают только когда серия закончилась.
- Повтор позиции три раза — ничья. Нет хода — поражение того, чей ход.

Белыми играет человек, чёрными — лифтёр. Его ходы считает альфа-бета.

## Из чего собрано

Игра целиком в браузере. База и вход для самой партии не нужны. Один экран, маршрут `/`.

- `src/game/game.ts` — сцены, ролики, кнопки, концовки.
- `src/game/checkers.ts` — правила и поиск хода. Проверка: `src/game/checkers.test.ts`.
- `src/game/audio.ts` — фоны и эффекты через Web Audio. Отдельных звуковых файлов нет, кроме дорожек внутри роликов.
- `src/game/art.ts` — загрузка картинок.
- `src/components/ElevatorGame.tsx` — холст и кнопки «Звук», «Начать игру», «Ещё раз».
- `public/game/` — картинки и ролики.
- `public/og.jpg`, `public/x-banner.jpg` — обложка для карточки.

Ролики:

- `chase.mp4` — погоня.
- `operator.mp4` — лифтёр спускается.
- `win-child.mp4` — качели.
- `win-dacha.mp4` — веранда с самоваром.
- `lose.mp4` — зелёная жижа.
- `draw-loop.mp4` — спираль на ничью.

Остальные концовки, панель, люк и старые кадры погони — картинки в той же папке. Если ролик ещё не готов, экран чёрный, старые нарисованные коридоры и фигурки не показываются.

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Сервер слушает порт 8080. Сборка и типы:

```bash
npm run build
npm run typecheck
```

Правила шашек:

```bash
node --experimental-strip-types --test src/game/checkers.test.ts
```
